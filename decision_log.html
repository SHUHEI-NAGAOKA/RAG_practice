4. 判断記録

#1 PDFのチャンク化設定

2026-11-14
決定内容
  • 埋め込みモデルは ruri v3 を使用し、ruri のトークナイザーでトークン数を数えてチャンク化する
  • max_tokens は 512 から試す
  • チャンク結果を JSON でも出力する
理由
  • max_tokens 512：最初の試行値として
  • JSON出力：チャンク結果を目視確認できるようにするため

#2 PDF変換（ドキュメント作成）の設定

2026-11-14
決定内容
  • backend は標準（ThreadedDoclingParseDocumentBackend）
  • OCR は RapidOCR（日本語 iso:ja）
  • 表構造認識は有効（do_table_structure=True）、精度方式は accurate
  • ページ画像・図の画像を生成（images_scale=1.0）
  • 出力は JSON と Markdown の両方
理由
  • 変換結果を目視確認するため
