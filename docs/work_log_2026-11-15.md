## 1. PDF → 階層つき Markdown

- 作成: `src/headings_to_md.py`
- 入力: 変換済み JSON `data/output/那須烏山市総合計画/那須烏山市総合計画.json`（PDF は再変換していない）
- 出力: `data/output/那須烏山市総合計画/那須烏山市総合計画_hierarchy.md`（見出し 558 件、本文・表を含む）
- 背景: Docling は見出し 565 件をすべて level 1 で出力するため、番号の付け方から深さを推定し直した

### 深さの判定規則（スタック方式）

| md | 見出しの例 |
|---|---|
| `#` | 表紙タイトル / 第１部・第２部・資料編 |
| `##` | Ⅰ.総論、Ⅱ．基本構想、基本目標N、【分野別計画 N …】 |
| `###` | １ … / Ⅱ …戦略（基本目標の直下） |
| `####` | （１）… |
| `#####` | ①… / A）… |
| 直前の見出しの1つ下 | 番号なし（■、【】、◇、施策の展開、現状と課題、指標 など） |

- 同じ種類の番号が再び出たら兄弟、初めての種類なら子として扱う
- 扉ページの「第１部」＋副題と、ページ上部に繰り返し出る「第１部 …」は見出しにせず、本文として残した
- md 生成時点で残った問題:
  1. 第１部「６ 政策の基本方向」の下の基本目標が子になっていない
  2. 「Ⅰ …戦略」が OCR でリスト項目になっていて見出しとして拾われない
  3. 見出しとして誤認識された文（例:「ます。」）が残っている
